D.Y.C ACADEMY WEBSITE
=====================

Open index.html in a browser.

IMPORTANT CUSTOMIZATION:
1. Replace assets/dyc-logo.png with the official D.Y.C Academy logo.
2. Replace assets/football-training.mp4 with your real football training/highlight video.
3. In watch.html, replace the YouTube iframe URL and channel link with the official D.Y.C Academy YouTube links.
4. Replace the 10 generated player JPEGs in assets/players/ with real player photos if available.
5. Edit the names, positions, stories and journey text in the players list inside the source generation or directly in players.html.

Pages:
Home, About, Latest > News, Latest > Transfer, Boys Team, Ladies Team, Events, Player Profiles, Watch, Contact Us.

Boys Team and Ladies Team link directly to the matching filtered Player Profile section.

CONTACT PAGE:
Replace the placeholder phone, email and exact location in contact.html. Add the academy's Google Maps link for the location button.
